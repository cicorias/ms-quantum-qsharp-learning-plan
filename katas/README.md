# Quantum Katas — pointers, mapped to the ramp

The **Quantum Katas** are Microsoft's self-paced Q# tutorials: each is a set of
theory lessons plus graded coding exercises with reference solutions.

## Where to run them

- **In VS Code** — the Azure Quantum Development Kit extension ships
  "QDK Learning"; open the command palette and search for the Katas /
  "QDK Learning" to work them inside the editor.
- **In the browser** — Code with Azure Quantum / Copilot:
  https://quantum.microsoft.com/en-us/tools/quantum-coding
- **Docs entry point** —
  https://learn.microsoft.com/en-us/azure/quantum/katas-qdk-learning
- **Classic Katas source (archived, still useful reading)** —
  https://github.com/microsoft/QuantumKatas

## Kata → phase map

| Kata | Ramp phase |
|------|-----------|
| Complex Arithmetic, Linear Algebra | 1 — Foundations |
| The Qubit, Single-Qubit Gates | 1–2 |
| Multi-Qubit Systems, Multi-Qubit Gates | 3 |
| Superposition | 2–3 |
| Measurements | 4 |
| Oracles / marking oracles | 4 |
| Deutsch–Jozsa Algorithm | 5 |
| Grover's Search | 5 |
| Quantum Fourier Transform | 5 |
| Teleportation, Superdense Coding | 5 |

Work the Kata for a topic, then re-implement the same idea from scratch in
`examples/` to make it stick.
