Model snippet

// A single-qubit superposition, measured
operation FlipCoin() : Result {
    use q = Qubit();      // starts in |0⟩
    H(q);                 // into equal superposition
    let r = MResetZ(q);   // measure AND reset in one step
    return r;             // Zero or One, ~50/50
}

📖 Fast glossary

QDKAzure Quantum Development Kit — Microsoft's toolkit: the Q# language, simulators, resource estimator, VS Code extension, and Python/Jupyter integration.
Q#Microsoft's high-level, hardware-agnostic quantum programming language. Separates quantum operations from classical functions.
operationA Q# subroutine that can act on qubits (has quantum side effects). Contrast with a function, which is deterministic classical code.
Qubit / ResultCore Q# types. A Qubit is a quantum bit reference; measuring it yields a Result of Zero or One.
SuperpositionA qubit being in a weighted combination of |0⟩ and |1⟩ until measured.
EntanglementA joint state of multiple qubits that can't be described independently; measuring one instantly constrains the others.
Adjoint / ControlledQ# functors that auto-generate the inverse of an operation, or a version conditioned on control qubits.
OracleA reversible quantum subroutine encoding a classical function; algorithms like Grover query it.
KatasMicrosoft's self-paced Q# tutorials (theory + graded exercises), now built into QDK Learning and the browser Copilot.
Resource EstimatorQDK tool that predicts the physical qubits and runtime an algorithm needs on a fault-tolerant machine.
