# 01 — Foundations: math + quantum concepts

Phase 1 of the Q# ramp, expanded into a starter → intermediate reference.

- **`foundations.html`** — the full interactive deep dive (open in a browser;
  math renders via MathJax). **Start here.**
- The numbered sub-section folders hold focused notes. Add your own material
  inside each as you go.

## Naming convention

Folders are zero-padded and ordered to match the roadmap. This is section
`01-foundations` (Phase 1 in `../../roadmap.html` / `../../CURRICULUM.md`).
Future sections get their own `NN-<name>/` folder under `docs/`, and
sub-sections inside are numbered the same way.

## How it connects to code

Each sub-section links to a runnable file in `../../examples/` and to the
matching Kata. Read the idea here, then run or implement it there.
