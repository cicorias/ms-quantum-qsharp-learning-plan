# 06 · Superposition & measurement

**Goal:** apply the Born rule, understand collapse, and see how the basis matters.

## Key ideas
- $P(0)=|\alpha|^2$, $P(1)=|\beta|^2$ (Born rule); measurement collapses the state.
- Relative phase is invisible in the $Z$ basis but visible in the $X$ basis.
- $|+\rangle$ is random in $Z$, deterministic in $X$.

`../../../examples/05_measurement_bases.qs` measures $|+\rangle$ in both $X$ and $Z$.
