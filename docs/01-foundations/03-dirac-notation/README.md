# 03 · Dirac (bra–ket) notation

**Goal:** read kets, bras, and inner/outer products fluently.

## Key ideas
- Ket $|\psi\rangle$ (column); bra $\langle\psi|$ (conjugate-transpose row).
- $\langle a|b\rangle$ is a number (inner product); $|a\rangle\langle b|$ is a matrix
  (outer product / projector).
- Basis: $|0\rangle=\bigl(\begin{smallmatrix}1\\0\end{smallmatrix}\bigr)$, $|1\rangle=\bigl(\begin{smallmatrix}0\\1\end{smallmatrix}\bigr)$.

## Worked
$\langle0|1\rangle=0$ (orthogonal); $|0\rangle\langle0|=\bigl(\begin{smallmatrix}1&0\\0&0\end{smallmatrix}\bigr)$ is the projector onto $|0\rangle$.

## Exercises
- Write $|+\rangle,|-\rangle$ as vectors and show $\langle+|-\rangle=0$.
- Compute the matrix $|0\rangle\langle1|$.
